# Centing Raja

**Centing Raja** is a stunting prevention and child growth monitoring platform designed for healthcare workers (*Tenaga Kesehatan*), community cadres (*Kader*), and parents (*Orang Tua*). The system enables continuous child growth tracking, automated WHO Z-score stunting assessments, educational material distribution, quizzes, and real-time task coordination.

---

## Features

- **Role-Based Access Control (RBAC):** Tailored workflows and permissions for Healthcare Workers, Cadres, and Parents.
- **Passwordless Auth:** Phone-number-based login using short-lived 6-digit OTP codes and JWT bearer tokens.
- **Child & Growth Tracking:** Comprehensive child profile management and periodic anthropometric measurement logging.
- **Automated Stunting Classification:** Real-time calculation of age in months, height-for-age WHO Z-scores, and stunting status categorization.
- **Cadre Task Management:** Task assignment and real-time measurement tracking for community posyandu sessions.
- **Education & Quizzes:** Educational modules, interactive quizzes, score tracking, and automated user notifications.

---

## Tech Stack

### Backend
- **Language & Runtime:** Go 1.23+
- **HTTP Framework:** Gin
- **Database:** PostgreSQL with `pgx/v5` connection pooling
- **Query Layer:** Type-safe Go queries generated by `sqlc`
- **Auth:** JWT (`golang-jwt/jwt/v5`) with HMAC SHA-256
- **API Specs:** Swagger / OpenAPI (`swaggo`)

### Frontend
- **Framework:** React 19 + TypeScript
- **Tooling:** Vite 8
- **Styling:** Tailwind CSS 4
- **Routing & State:** React Router v7, React Context
- **Icons & Motion:** Lucide React, Framer Motion

## Getting Started

### Prerequisites
- [Go](https://go.dev/) 1.23 or newer
- [Node.js](https://nodejs.org/) 20+ and [pnpm](https://pnpm.io/)
- [Docker](https://www.docker.com/) & Docker Compose

---

### Backend Setup

1. **Start the database:**
   ```bash
   cd backend
   docker compose up -d
   ```

2. **Configure environment variables:**
   Create a `.env` file in `backend/`:
   ```env
   PORT=8080
   DB_CONN_STRING=postgresql://prabowo:prabowo@127.0.0.1:5432/centing_dev
   JWT_SECRET=your_secure_jwt_secret_key
   ```

3. **Apply database schema and start server:**
   ```bash
   # Apply schema (if not initialized by docker-entrypoint)
   psql -U prabowo -d centing_dev -f schema/schema.sql

   # Run backend
   go run main.go
   ```

   The REST API will be available at `http://localhost:8080`. Interactive Swagger UI is hosted at `http://localhost:8080/swagger/index.html`.

4. **Run tests:**
   ```bash
   go test ./...
   ```

---

### Frontend Setup

1. **Install dependencies:**
   ```bash
   cd frontend
   pnpm install
   ```

2. **Run development server:**
   ```bash
   pnpm dev
   ```

   The frontend will run at `http://localhost:5173`.

3. **Build for production:**
   ```bash
   pnpm build
   ```
